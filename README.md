# 🔎 Duplicate Finder

A lightweight Python CLI tool that finds duplicate files using SHA-256 hashes.

## Features

- Scan folders recursively
- Compare file contents
- Detect duplicate files
- Uses SHA-256 hashing
- No external dependencies

## Run

```bash
python main.py
```

## Example

```text
🔎 Duplicate Finder
========================================

Duplicate files:
  • ./documents/copy.txt
  • ./backup/copy.txt
```

## Built With

- Python
- hashlib
- os
- collections
